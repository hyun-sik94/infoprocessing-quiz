[백엔드 및 채점 로직]

* 대소문자와 공백을 무시하는 유연한 주관식 검색 및 채점 기능
* 복수 정답 요구 시 여러 칸으로 나누어 개별 채점하는 기능
* 파이프 기호를 이용한 동의어 및 유사 정답 인정 기능
* 선택한 연도별 혹은 전체 무작위 30문항 모의고사 세션 생성 기능
* 브라우저 고유 식별값(Device Fingerprint)을 활용한 제보 도배 및 어뷰징 방지 기능

[프론트엔드 및 사용자 기능]

* 1번부터 끝까지 푸는 순차 풀이 모드 및 중간 저장, 이어풀기 기능
* 문제 풀이 화면에서 보기 항목을 버튼으로 자동 추출하여 터치 시 입력란에 자동 기입되는 슬림 뱃지 기능
* 브라우저 로컬 스토리지를 활용한 즐겨찾기 문제 보관 및 전용 모의고사 기능
* 과거 모의고사 풀이 이력, 최종 점수, 오답 노트를 누적하여 다시 확인하고 개별 삭제하는 기능
* 문제 풀이 도중 출제 정답과 해설을 즉시 확인하고 숨길 수 있는 인라인 토글 기능
* 필기(객관식 CBT) 모드와 실기(주관식 단답형) 모드 간 자유로운 실시간 전환 기능
* 과목별 정답률 통계 시각화 및 자주 틀리는 취약 문제 원클릭 풀이 기능

[모바일 반응형 렌더링 엔진]

* 지시문과 세부 설명을 자동으로 분리하여 포인트 카드로 나누어 주는 가시성 향상 렌더링
* 실제 빈칸 기호(원문자, 괄호)만 감지하여 눈에 띄는 노란색 점선 배지로 자동 치환하는 하이라이트 기능 (SQL 자료형이나 함수 괄호 오작동 원천 차단)
* 파이프(|) 구분 텍스트를 모바일 좌우 스크롤이 가능한 격자형 반응형 표(Table)로 자동 변환하는 파서
* 1열 기호 및 라벨의 가로폭 고정 및 줄바꿈 방지(nowrap) 처리로 행렬 어긋남 방지
* 단일 열(1열) 테이블 구조 감지 및 자동 표 변환 대응
* 소스코드(C, Java) 및 순서도 감지 보호: 논리 연산자(||)가 포함된 코드가 표로 깨지지 않고 어두운 에디터 테마 박스로 보존되는 코드 가드 기능
* 표와 함께 섞인 보기 영역을 분리하여 내용물 크기에 딱 맞춘 슬림 인라인 칩 카드로 독립 출력

[데이터베이스 및 문제 데이터 정제]

* 전체 192개 실기 기출문제의 배점 표기(5점) 일괄 제거
* 인공지능 출처 인용 태그(cite) 전면 제거 및 해설 문맥 정돈
* 3단 디자인 패턴 목록의 모바일 맞춤형 카테고리(생성, 구조, 행위) 목록 구조화
* 테스트 케이스 및 릴레이션 테이블 데이터의 무단 개행 교정 및 무결성 정비
